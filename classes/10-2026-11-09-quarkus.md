# 10 · Quarkus: primer módulo MicroProfile

Proyecto: [`app-authors`](../code/prog-distribuida/app-authors), paquete `com.programacion.distribuida.authors`. Perfiles y MicroProfile: [nota 07](07-2026-10-30-jakarta-ee-tomcat.md); anotaciones REST: [nota 08](08-2026-11-05-jakarta-rest-servidores.md).

## Creación del módulo
- Generador: <https://code.quarkus.io/?b=GRADLE_KOTLIN_DSL&e=rest&extension-search=rest>, como referencia.
- En clase el módulo se crea **manualmente**, sin el starter.
- Paquetes: `db`, `dtos`, `repo`, `rest`, `services`.

## Dependencias (Quarkus 3.40.1.1)

| Área | Artefacto |
|---|---|
| Versiones | `enforcedPlatform("io.quarkus.platform:quarkus-bom")` |
| CDI | `quarkus-arc` (ArC, Jakarta CDI 4.1.0) |
| REST | `quarkus-rest` |
| JSON | `quarkus-rest-jsonb` |

Plugins: `io.quarkus` y `io.freefair.lombok`.

## REST en Quarkus
- `@ApplicationPath` no es necesario: `@Path("/config")` responde directamente en `/config`.
- `quarkus-rest` procesa en tiempo de construcción y se ejecuta sobre Vert.x.
- ArC resuelve la inyección CDI en tiempo de compilación.

## Configuración

| Archivo | Alcance |
|---|---|
| `application.properties` | Quarkus |
| `META-INF/microprofile-config.properties` | MicroProfile Config |

## Modos de ejecución

| Modo | Tarea | Perfil | Características |
|---|---|---|---|
| Desarrollo | `quarkusDev` | `dev` | Live coding, Dev UI, debug en el puerto 5005 |
| Producción | `quarkusBuild` + `java -jar` | `prod` | Ejecuta el empaquetado final |

- Dev UI: `http://localhost:8080/q/dev-ui/extensions` (extensiones, beans CDI, endpoints y configuración).
- Las tareas están en `app-authors > Tasks > quarkus`.

## Empaquetado
`quarkusBuild` genera `build/quarkus-app/`: `quarkus-run.jar`, `app/`, `lib/` y `quarkus/`.

```bash
cd app-authors/build/quarkus-app
java -jar quarkus-run.jar
```

- `quarkus-run.jar` no es un fat JAR: necesita las carpetas vecinas, por lo que se distribuye `quarkus-app/` completa.
- Features instaladas: `cdi`, `rest`, `rest-jsonb`, `smallrye-context-propagation`, `vertx`.

## Errores

| Síntoma | Causa |
|---|---|
| `no se ha encontrado o cargado la clase principal jar` | Falta el guion: es `java -jar` |
| `Unable to access jarfile quarkus-run.jar` | Se ejecutó dentro de `quarkus-app/quarkus`; el JAR está en `quarkus-app/` |
