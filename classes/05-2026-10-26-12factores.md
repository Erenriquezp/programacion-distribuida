# 05 · Twelve-Factor (V–VIII)

Factores I–IV: [04](04-2026-10-23-serverless-arquitecturas-12factores.md#twelve-factor-app).

## V. Build, release, run
Separar estrictamente las etapas que convierten código en ejecutable:

| Etapa | Qué ocurre | Ejemplo |
|---|---|---|
| Build | Se compila y genera el artefacto | JAR / WAR |
| Release | Artefacto + configuración del ambiente | Imagen Docker |
| Run | Se ejecuta la release en el ambiente elegido | Contenedor en ejecución |

## VI. Processes
- Procesos *stateless*: no guardan estado local entre peticiones.
- La instancia puede eliminarse y reemplazarse en cualquier momento.
- El estado necesario va a un backing service, p. ej. caché en memoria (Redis).

## VII. Port binding
- La app es autocontenida: expone su servicio enlazándose a un puerto, sin servidor externo.
- "En vez de llevar la app al servidor, llevamos el servidor a la app" (servidores embebidos).

## VIII. Concurrency
- Escalar mediante procesos: primero vertical, luego horizontal (más instancias).
- Componentes de apoyo: gateway, balanceador de carga, orquestador, registro de servicios, firewall.
- Tráfico interno por HTTP; externo por HTTPS.
