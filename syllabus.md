# Programación Distribuida (TGP10BFT01)

- **Carrera:** Computación, UCE — 10.º semestre, 2026-2027, presencial
- **Prerrequisito:** Programación Concurrente y Paralela (TGP09BFT04)
- **Horas:** 64 docente + 32 práctico-experimental + 64 autónomo = 160

## Resultado de aprendizaje
Construir aplicaciones Cloud Native con CDI, REST y microservicios, usando estándares Jakarta EE (MicroProfile) y Spring.
